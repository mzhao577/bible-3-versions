## English

Subject: Request for Recovery Version text data file (personal study use)

Dear Living Stream Ministry,

I am a reader of the Recovery Version and have built a small personal study
tool that shows one verse at a time across three translations side by side:
the Chinese Recovery Version, the Chinese Union Version, and the King James
Version. The latter two are public domain; the Recovery Version is not, and I
do not want to obtain it from an unauthorised source.

May I ask:

1. Is a text data file of the Chinese Recovery Version (CSV, JSON, XML or
   SQLite) available for personal, offline use on my own computer?
2. If so, what licence or fee applies?
3. If no data file is offered, is there another route you would recommend?

The tool runs only on my own machine. I will not publish or redistribute the
Recovery Version text. [If applicable: I own a purchased copy of ….]
